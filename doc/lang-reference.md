# Zeta 语言参考手册

本文档基于 `src/compiler/zeta.l`、`src/compiler/zeta.y`、`src/compiler/translate.cpp`、`src/vm/vm.cpp`、`src/vm/value.h` 等源码整理，描述当前 Zeta 语言实现的实际语法与运行语义。`tests/` 中的 `.zt` 文件是示例和测试，但不作为唯一依据；若测试与本文档不一致，以本文档（及源码）为准。

Zeta 是一种轻量级、面向对象、动态类型、基于字节码虚拟机（VM）的脚本语言。前端使用 Flex/Bison 生成语法分析器，运行时为栈式字节码解释器，并带有分代式垃圾回收（GC）。

---

## 1. 命令行使用

```
zeta [选项] <file>
```

默认动作是运行：若 `<file>` 是 `.zt` 源文件则编译后运行；若是 `.ztc` 字节码文件则直接运行。

| 选项 | 说明 |
|------|------|
| `-v`, `--version` | 输出版本号并退出 |
| `-h`, `--help` | 输出帮助信息并退出 |
| `-c`, `--compile` | 将 `.zt` 源文件编译为 `.ztc` 字节码文件 |
| `-r`, `--run` | 强制以运行模式执行；自动识别 `.zt` / `.ztc` |
| `-d`, `--dump` | 将 `.ztc` 字节码文件转储为可读文本（默认输出 `<file>.ztc.dump`） |
| `-o`, `--output` | 指定 `-c` / `-d` 的输出文件名 |
| `-s`, `--stack-size <KiB>` | 设置 VM 栈大小（默认 1024 KiB） |
| `-i`, `--init-heap-size <KiB>` | 设置初始堆大小（默认 1024 KiB） |
| `-m`, `--max-heap-size <KiB>` | 设置最大堆大小，`-1` 表示不限制（默认 `-1`） |
| `-p`, `--module-search-path <path>` | 添加模块搜索路径，可多次指定 |

退出码约定：

- `0`：成功
- `1`：本地错误（如编译失败、文件不存在）
- `2`：VM 异常（如栈溢出、堆超限）
- `3`：运行时错误（如断言失败、类型错误）

入口约定：运行源文件时，VM 会在模块全局符号中查找名为 `main` 的函数，并以 0 个参数调用它。

## 2. 词法结构

### 2.1 注释

支持两种注释：

```
// 行注释

/*
   块注释
*/
```

块注释不嵌套。注释等价于空白。

### 2.2 标识符

标识符由字母、数字、下划线组成，且不能以数字开头：

```
[a-zA-Z_][a-zA-Z0-9_]*
```

### 2.3 关键字

以下单词是保留关键字，不能作为标识符：

```
var let fn return if else while for break continue
class extends this import as super is null true false
```

### 2.4 字面量

#### 整数

支持十进制、二进制、八进制、十六进制，数字间可用下划线 `_` 分隔：

| 形式 | 示例 |
|------|------|
| 十进制 | `42`、`1_000_000` |
| 十六进制 | `0xFF`、`0X1A` |
| 二进制 | `0b1010`、`0B1111` |
| 八进制 | `0o777`、`0o10` |

整数字面量在实现中为 64 位有符号整数（`int64_t`）。`0` 是合法的十进制零。

#### 浮点数

支持普通小数和科学计数法，也支持下划线分隔：

```
3.14
0.5
1e5
2.5e-3
1_000.5
```

#### 字符串

支持单引号和双引号两种字符串字面量：

```
"hello"
'world'
""
```

支持的转义序列：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |

未知转义序列会保留反斜杠和原字符（源码中注释为“至少应该给个警告”，当前未产生警告）。

#### 布尔与空值

```
true
false
null
```

### 2.5 语句分隔

语句以分号 `;` 结尾。空语句 `;` 合法。`fn` 声明和 `class` 声明不需要在末尾加分号，变量声明、赋值、`return`、`break`、`continue`、表达式语句等需要分号。

## 3. 程序结构

一个 Zeta 源文件（`.zt`）由以下部分组成：

1. 可选的 `import` 声明；
2. 若干顶层声明：`var` / `let` 全局变量、`fn` 函数、`class` 类。

示例：

```
import "tests/module/mod_a" as a;

var counter = 0;
let PI = 3.14159;

fn add(a, b) {
    return a + b;
}

class Point {
    var x = 0;
    var y = 0;
}
```

顶层声明的顺序不影响符号解析：编译器先登记所有顶层全局符号，再逐个生成代码，因此函数可以互相调用，也可以在定义之前引用。

## 4. 类型与值

Zeta 是动态类型语言，变量不声明类型。值在运行时有类型标签。

### 4.1 值类型

| 类型 | 说明 |
|------|------|
| `null` | 空值，只有一个值 `null` |
| `Bool` | 布尔值 `true` / `false` |
| `Int` | 64 位有符号整数 |
| `Float` | 64 位双精度浮点数 |
| `String` | 驻留（interned）字符串，VM 直接管理，内容不可变；字符串字面量和编译期折叠出的字符串属于该类型 |
| `StrObj` | GC 管理的字符串对象；运行时字符串拼接、`input()`、`str()` 等产生该类型 |
| `Function` | 函数值，包括具名函数和函数字面量 |
| `Class` | 类对象，可通过调用它来创建实例 |
| `Instance` | 类的实例对象 |
| `Array` | 动态数组 |
| `Map` | 字符串键到值的映射 |
| `Iterator` | 迭代器，用于 `for-in` 或 `iter()` / `next()` |
| `Error` | 错误标记值，携带整数错误码，用于迭代终止和错误检查 |

`type()` 内置函数返回的字符串与上表基本一致：`"Null"`、`"Bool"`、`"Int"`、`"Float"`、`"String"`、`"StrObj"`、`"Function"`、`"Class"`、`"Instance"`、`"Array"`、`"Map"`、`"Iterator"`、`"Error"`。

### 4.2 字符串的两种形态

- **`String`（驻留字符串）**：字符串字面量、编译期常量折叠产生的字符串属于这种类型。它被 VM 内部驻留，可以作为 Map 的键。
- **`StrObj`（GC 字符串对象）**：运行时字符串拼接（例如 `s1 + "lo"`，其中 `s1` 是变量）、`input()`、`str()` 产生这种类型。

两者用 `==` 比较时按内容比较；用 `is` 比较时要求类型和值完全相同，因此 `"ab"` 和 `"a" + "b"`（运行时拼接出的 `StrObj`）不满足 `is`，但满足 `==`。可以使用 `intern()` 把 `StrObj` 转换为驻留 `String`。

### 4.3 真值规则

在 `if`、`while`、`!`、`&&`、`||`、`?:` 等需要条件的位置，以下值视为假：

- `null`
- `false`
- `0`
- `0.0`
- 空字符串（`String` 或 `StrObj`）
- 空数组
- 空映射

其余值视为真，包括非零数字、非空字符串/数组/映射、函数、类、实例、迭代器、`Error`。

### 4.4 相等与同一

- `==` / `!=` 是值相等比较：
  - Int 与 Float 可以跨类型数值比较；
  - 字符串按内容比较（`String` 与 `StrObj` 之间也可以）；
  - 实例若在其所属类中定义了 `_equals(other)` 方法，则委托该方法比较；该方法必须恰好接收 1 个参数（不包括 `this`）并返回 Bool；当前实现不沿继承链查找 `_equals`；
  - 实例未定义 `_equals` 时，只有同一对象才相等（不同实例即使内容相同也不相等）；
  - 其他对象（数组、映射、类、迭代器等）按指针比较；
  - 任意两个 `Error` 值 `==` 比较均为 `true`（不比较错误码）。
- `is` 是严格同一性比较：要求类型和值/指针完全相同，不进行跨类型数值转换，不调用 `_equals`。例如 `0 == 0.0` 为 `true`，但 `0 is 0.0` 为 `false`；`error(1) is error(1)` 为 `true`，`error(1) is error(2)` 为 `false`。

### 4.5 类型转换内置函数

- `int(x)`：转为 Int。Float 向零截断；Bool 转 `1`/`0`；数字字符串可解析。
- `float(x)`：转为 Float。Int、Bool、数字字符串可转换。
- `str(x)`：转为字符串。Int 和 Float 会生成 `StrObj`；Bool 和 `null` 会返回驻留 `String`（如 `"true"`、`"null"`）。Float 使用 C++ `std::to_string` 风格（例如 `3.14` 转为 `"3.140000"`）。

## 5. 变量与作用域

### 5.1 声明

使用 `var` 声明可变变量，使用 `let` 声明不可变变量：

```
var x;          // 未初始化时值为 null
var y = 10;
let z = "hello"; // 不可变
```

可以在一条语句中声明多个变量：

```
var a = 1, b = 2, c = 3;
```

`let` 也允许不写初始值（值为 `null`），但既然不可变，通常应给出初始值。

### 5.2 局部变量与作用域

- 函数参数是局部变量，属于函数最外层作用域。
- 块 `{ ... }` 会创建新的局部作用域。
- 内层块可以访问外层变量，也可以声明同名变量遮蔽外层变量。
- 同一作用域内不能重复声明同名变量。
- 未初始化的局部变量默认值为 `null`。
- 对 `let` 声明的局部变量赋值会在编译期报错。

示例：

```
fn main() {
    var x = "outer";
    {
        var x = "inner";
        assert(x == "inner");
    }
    assert(x == "outer");
}
```

### 5.3 全局变量

顶层 `var` / `let` 是全局变量。全局变量初始化有以下限制：

- 初始化表达式必须是编译期可求值的常量表达式。
- 因此全局变量的初始化目前支持数字、字符串、布尔、`null`、可折叠为编译期常量的映射字面量（例如所有值均为字面量）、函数字面量，以及它们的常量折叠结果；不支持数组字面量、函数调用或变量引用。
- 未初始化时默认值为 `null`。

> 已知限制：`let` 的不可变性目前只在局部变量赋值时被编译器检查；全局 `let` 被赋值不会报错。这是当前实现的一个不一致点，建议按“全局 `let` 也不应赋值”来使用。

### 5.4 赋值

支持简单赋值和复合赋值：

```
x = expr;
x += expr;
x -= expr;
x *= expr;
x /= expr;
x %= expr;
x &= expr;
x |= expr;
x ^= expr;
x <<= expr;
x >>= expr;
```

复合赋值会读取目标当前值，与右侧表达式运算后再写回。赋值目标可以是局部变量、全局变量、实例字段、数组元素、映射键。

## 6. 表达式与运算符

### 6.1 算术运算

```
+  -  *  /  %  一元 -
```

- Int 与 Int 运算产生 Int；除法是整数除法（向零截断）。
- Float 参与时结果为 Float。
- Int 与 Float 混合时，Int 提升为 Float。
- Int 除零或取模零会产生运行时错误。
- 字符串 `+` 表示字符串拼接；两个字符串（`String` 或 `StrObj`）都可以拼接，结果类型为 `StrObj`，除非在编译期被常量折叠为 `String`。
- 一元 `-` 只能用于 Int 或 Float。

### 6.2 比较运算

```
==  !=  <  >  <=  >=  is
```

- 数值比较支持 Int/Float 混合。
- `<`、`>`、`<=`、`>=` 只支持数值比较。
- `==` / `!=` 按 4.4 节规则。
- `is` 按严格同一性比较。

### 6.3 逻辑运算

```
&&  ||  !
```

- `&&`：先求左操作数；若左操作数为假，返回左操作数本身；否则求右操作数并返回右操作数。结果不一定是 Bool。
- `||`：先求左操作数；若左操作数为真，返回左操作数本身；否则求右操作数并返回右操作数。结果不一定是 Bool。
- `!`：按真值规则取反，结果一定是 Bool。
- `&&` 和 `||` 都短路求值。

### 6.4 位运算与移位

```
&  |  ^  ~  <<  >>
```

- 仅支持 Int 操作数。
- `~` 是按位取反。
- 移位右操作数为 Int 位数。

### 6.5 三元条件

```
cond ? then_expr : else_expr
```

条件按真值规则判断，只求值被选中的分支。

### 6.6 调用、成员与索引

```
f(args)          // 函数调用
obj.method(args) // 方法调用
obj.field        // 字段访问
obj[expr]        // 数组索引或 Map 键访问
super.method(args)
```

- 函数、方法、类的调用参数数量有上限：`uint8_t`，即最多 255 个参数。
- 方法调用与字段访问是不同语法：`obj.name(args)` 走方法分派；`(obj.name)(args)` 会先读取字段再作为函数调用。

### 6.7 运算符优先级

按从高到低排列（同级别从左到右结合，赋值从右到左）：

| 优先级 | 运算符 |
|--------|--------|
| 最高 | 字面量、标识符、`this`、`(...)` |
| 成员/调用 | `.`、`.method()`、`()`、`[]`、`super.method()` |
| 一元 | `-`（负号）、`!`、`~` |
| 位运算 | `&`、`|`、`^`（同一优先级，左结合） |
| 乘除模 | `*`、`/`、`%` |
| 加减 | `+`、`-` |
| 移位 | `<<`、`>>` |
| 关系 | `==`、`!=`、`<`、`>`、`<=`、`>=`、`is` |
| 逻辑与 | `&&` |
| 逻辑或 | `||` |
| 三元 | `?:` |
| 最低 | 赋值 `=`、`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=` |

### 6.8 编译期常量折叠

编译器会对部分字面量表达式做常量折叠，例如：

```
1 + 2            // 折叠为 Int 3
"a" + "b"        // 折叠为驻留 String "ab"
true ? 1 : 2     // 折叠为 Int 1
```

折叠后的字符串是 `String` 而不是 `StrObj`。折叠结果与运行时语义保持一致，尤其是 `&&` / `||` 返回操作数值本身。

## 7. 语句

### 7.1 表达式语句

```
expr;
```

表达式结果会被丢弃。

### 7.2 块

```
{
    stmt1;
    stmt2;
}
```

块创建新作用域。

### 7.3 if / else

```
if (cond) stmt
if (cond) stmt else stmt
```

`cond` 使用真值规则。`else` 与最近的未匹配 `if` 结合。

### 7.4 while

```
while (cond) stmt
```

`cond` 使用真值规则。

### 7.5 for-in

```
for (item : iterable) stmt
```

- 对数组：迭代数组元素。
- 对映射：迭代键。
- 对类实例：调用其 `_iter()` 方法获得迭代器，然后不断调用 `_next()` 直到返回 `Error`。
- 循环变量在每次迭代开始时被赋值为当前元素/键。
- 循环变量在 `for` 内部是可变局部变量，但每次迭代会重新赋值。

### 7.6 break / continue

- `break`：跳出当前最内层 `while` 或 `for-in`。
- `continue`：跳到当前最内层循环的下一次迭代。
- 在循环外使用会在编译期报错。

### 7.7 return

```
return;
return expr;
```

- 无表达式的 `return` 返回 `null`。
- 函数体自然结束也返回 `null`（编译器会在函数末尾自动补 `return null`）。
- 构造函数通常写 `return this`，但运行期不强制。

### 7.8 空语句

单独的分号 `;` 是空语句，不执行任何操作。

## 8. 函数

### 8.1 具名函数

```
fn add(a, b) {
    return a + b;
}
```

- 函数是全局符号，可作为值传递、存入数组/映射、作为参数或返回值。
- 函数可以在定义前被调用（因为全局符号先登记）。
- 函数没有默认参数、可变参数、命名参数。

### 8.2 函数字面量（匿名函数 / lambda）

```
fn(x) { return x * 2; }
fn() { return 1; }
```

函数字面量也是 `Function` 值。

### 8.3 高阶函数

函数是一等值，因此可以写出 `map` / `filter` / `reduce` 等模式：

```
fn apply(f, x) {
    return f(x);
}

fn main() {
    var result = apply(fn(y) { return y + 1; }, 10);
    println(result);
}
```

### 8.4 闭包限制

当前实现**不支持闭包捕获外层局部变量**。函数字面量只能访问：

- 自己的参数；
- 全局变量；
- 其他全局函数/类。

函数字面量不能访问定义它的外层函数中的局部变量（除非该名字碰巧是全局变量）。这是当前实现的已知限制。

### 8.5 递归

具名函数可以递归调用自己，因为函数名是全局符号。示例：

```
fn factorial(n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

### 8.6 参数与返回值

- 函数参数按位置传递，参数个数必须与函数声明一致，否则运行时错误。
- 普通函数调用参数上限 255 个。
- 所有函数都会返回一个值；没有 `return` 或 `return;` 时返回 `null`。

## 9. 类与面向对象

### 9.1 类声明

```
class Point {
    var x = 0;
    var y = 0;

    fn set_x(v) {
        this.x = v;
        return this;
    }
}
```

- 类成员包含字段（实例变量）和方法。
- 字段必须用 `var` 声明，不能用 `let`（编译期报错）。
- 字段初始化值必须是常量表达式；未初始化时默认 `null`。
- 方法内用 `this` 访问当前实例。

### 9.2 实例化

类是值，调用类即创建实例：

```
var p = Point();
```

若类中定义了 `_init` 方法，则实例化时调用它作为构造函数：

```
class Vec3 {
    var x = 0;
    var y = 0;
    var z = 0;

    fn _init(vx, vy, vz) {
        this.x = vx;
        this.y = vy;
        this.z = vz;
        return this;
    }
}

var v = Vec3(1, 2, 3);
```

- 无 `_init` 时，实例字段使用类中声明的默认值；此时应使用零参数实例化（当前实现不会检查额外参数，传参可能造成运行时栈错误）。
- 构造函数参数个数不包括 `this`；`Point(1, 2)` 对应 `_init(a, b)`。
- `_init` 不沿继承链继承；子类若需要父类构造逻辑，应在自己的 `_init` 中显式调用 `super._init(...)`。
- 构造函数应当显式 `return this;`。若 `_init` 返回其他值，实例化表达式的返回值将是该值而不是新实例（当前编译器不检查这一错误）。

### 9.3 字段与方法

- 实例字段通过 `.` 访问和赋值；对不存在的字段赋值会自动创建该字段，读取不存在的字段会报运行时错误。
- 方法通过 `obj.method(args)` 调用；VM 会在实例的类及祖先类的方法表中查找方法。
- 方法内部 `this` 始终是调用该方法的实例；`this` 只能用于方法内，在普通函数中使用会在编译期报错。
- 方法支持链式调用，例如 `p.set_x(1).set_y(2)`。

### 9.4 继承

```
class Animal {
    var name = "";
    fn speak() { return "Animal " + this.name; }
}

class Dog extends Animal {
    var breed = "";
    fn speak() { return "Dog " + this.name; }
}
```

- 子类实例会继承父类字段（父类默认值会被复制到实例字段表）。
- 普通方法会继承；子类可以重写父类方法，方法查找从实例的实际类开始，沿继承链向上查找。
- 特殊协议方法（`_init`、`_equals`、`_iter`、`_next`）当前不自动继承，详见 9.7 节。
- 继承语法支持跨模块：`class C extends mod.Base { ... }`，其中 `mod` 是模块别名。

### 9.5 super 调用

```
super.method(args);
```

- `super` 只能在方法内使用。
- `super.method()` 从“当前方法所属类的父类”开始向上查找方法，而不是从实例的实际类开始。
- 因此多级继承链中，每一层的 `super` 都会从该层方法定义所在的类向上解析。
- `super._init(...)` 可用于在子类构造函数中调用父类构造函数。

另外，也可以通过“类名直接调用方法”的方式调用祖先类方法，例如：

```
class A { fn who() { return "A"; } }
class B extends A { fn who() { return "B+" + super.who(); } }

fn main() {
    var b = B();
    assert(B.who(b) == "B+A");
    assert(A.who(b) == "A");
}
```

通过类名调用方法时，第一个参数作为 `this` 传入。注意：通过类名调用方法只查找该类自身的方法表，不会沿继承链向上查找。

### 9.6 类作为值

- 类可以赋值给变量、存入数组/映射、作为参数/返回值。
- 通过保存类的变量调用它同样可以实例化。

### 9.7 特殊协议方法

以下方法名具有特殊运行时含义：

| 方法 | 用途 |
|------|------|
| `_init` | 构造函数 |
| `_equals(other)` | 自定义 `==` / `!=` 的实例比较；必须接收 1 个参数并返回 Bool |
| `_iter()` | 自定义 `for-in` / `iter()` 时返回迭代器 |
| `_next()` | 自定义迭代器的“取下一个元素”方法；无参数，迭代结束时返回 `error(0)` |

> 当前实现中，这些特殊方法按“实例所属类自己的方法表”直接查找，不沿继承链自动继承。如果父类定义了这些方法而子类没有，子类实例不会自动获得父类的构造/比较/迭代行为；请在子类中显式定义或通过 `super` 调用父类实现。

## 10. 模块系统

### 10.1 导入

```
import "path/to/module";
import "path/to/module" as alias;
```

- 导入路径是模块名，**不带扩展名**。
- 例如 `import "tests/module/mod_a"` 会查找 `tests/module/mod_a.ztc` 或 `tests/module/mod_a.zt`。
- 带 `as` 时，通过 `alias.symbol` 访问该模块的全局符号。
- 不带 `as` 时，该模块的全局符号可作为当前模块的未限定名称使用。

### 10.2 查找顺序

对于 `import "name"`，VM 按以下顺序查找模块文件：

1. 相对于“导入该模块的模块”所在目录：`<base_dir>/name.ztc`，然后是 `<base_dir>/name.zt`；
2. 相对于当前工作目录（或绝对路径）；
3. 依次在 `-p` 指定的模块搜索路径中查找。

`.ztc` 优先于 `.zt`。

### 10.3 符号解析

- 使用别名时，`alias.name` 会解析为指定模块中名为 `name` 的全局符号。
- 不使用别名时，未限定名称会按 `import` 的声明顺序在已导入模块中查找；如果多个模块都定义了同名符号，则使用第一个导入模块中的定义。官方建议避免依赖这种顺序，必要时使用别名。
- 若模块别名与当前模块的全局符号同名，别名优先。
- 同一个 VM 中每个模块只加载一次，所有模块共享全局运行时状态；因此模块级 `var` 是跨模块共享的可变状态。
- 模块之间允许传递依赖：A 导入 B，B 导入 C；A 中只能直接使用 A 的 `imports` 中列出的模块符号，不能直接使用 B 的内部依赖 C（除非 A 自己也导入 C）。

### 10.4 模块导出

Zeta 没有显式的 `export` 关键字。模块的所有顶层 `var` / `let`、函数、类默认对导入者可见。

## 11. 内置函数

以下函数由 VM 直接实现，不需要从任何模块导入。它们也是保留的全局名字，不能用来声明同名函数（编译期会报冲突）。

| 函数 | 签名 | 说明 |
|------|------|------|
| `iter` | `iter(container)` | 返回容器或类实例的迭代器 |
| `next` | `next(iter)` | 取迭代器的下一个元素；迭代结束返回 `Error` |
| `array` | `array(size)` | 创建指定大小的数组，元素初始化为 `null` |
| `map` | `map(capacity)` | 创建空映射，`capacity` 为初始容量提示 |
| `print` | `print(val)` | 打印值到标准输出，不换行；返回 `null` |
| `println` | `println(val)` | 同 `print`，但末尾换行；返回 `null` |
| `input` | `input()` | 从标准输入读取一个以空白分隔的字符串，返回 `StrObj` |
| `error` | `error(code)` | 创建一个错误码为 `code` 的 `Error` 值 |
| `check` | `check(val)` | 若 `val` 是 `Error` 返回 `false`，否则返回 `true` |
| `intern` | `intern(strObj)` | 将 `StrObj` 驻留为 `String` 并返回；用于 Map 键 |
| `type` | `type(val)` | 返回类型名字符串（驻留 `String`） |
| `int` | `int(val)` | 转换为 Int |
| `float` | `float(val)` | 转换为 Float |
| `str` | `str(val)` | 转换为字符串；Int/Float 生成 `StrObj`，Bool/`null` 返回 `String` |
| `assert` | `assert(cond)` | `cond` 必须是 Bool；若为 `false` 抛出运行时错误 |

### 11.1 打印格式

`print` / `println` 对不同类型的输出格式：

| 值 | 输出 |
|------|------|
| `null` | `null` |
| `Bool` | `true` / `false` |
| `Int` | 十进制整数 |
| `Float` | 使用 C++ `cout` 默认格式 |
| `String` / `StrObj` | 字符串内容（不含引号） |
| `Function` | `<function>` |
| `Array` | `<array>` |
| `Map` | `<map>` |
| `Class` | `<class>` |
| `Instance` | `<instance>` |
| `Iterator` | `<iterator>` |
| `Error` | `<error>` |

### 11.2 assert 的特殊性

`assert()` **要求参数必须是 Bool 类型**，不会使用真值规则。传入非 Bool 会得到运行时错误：“Assert: condition must be a boolean”。因此不要写 `assert(x)`（除非 `x` 本身就是 Bool），而应写 `assert(x == ...)` 或 `assert(check(x))` 等。

## 12. 内置方法

| 接收者 | 方法 | 签名 | 说明 |
|--------|------|------|------|
| 数组 | `size` | `arr.size()` | 返回数组元素个数 |
| 数组 | `add` | `arr.add(value)` | 在数组末尾追加一个元素；返回 `null` |
| 映射 | `size` | `m.size()` | 返回映射键值对个数 |
| `String` / `StrObj` | `len` | `s.len()` | 返回字符串长度（字节数） |

数组、映射、字符串的内置方法由 VM 直接处理，不经过类方法表。实例也可以定义同名方法，实例方法调用会走正常方法分派。

## 13. 迭代协议

### 13.1 数组和映射

- `iter([1, 2, 3])` 返回数组迭代器，`next` 依次返回元素。
- `iter({a: 1})` 返回映射迭代器，`next` 依次返回键（驻留 `String`）。
- 迭代结束后，`next` 返回 `Error`，`check(next(...))` 为 `false`。

### 13.2 自定义类迭代

一个类只要实现 `_iter()` 和 `_next()` 就可以被 `for-in` 使用：

```
class Range {
    fn _iter() {
        return RangeIter(this.start, this.end);
    }
}

class RangeIter {
    fn _next() {
        if (this.current >= this.end) {
            return error(0);
        }
        var v = this.current;
        this.current = this.current + 1;
        return v;
    }
}
```

- `_iter()` 必须返回一个迭代器对象（通常是一个类实例）。
- `_next()` 每调用一次返回下一个元素；迭代结束时返回 `error(0)`。
- `for-in` 的展开等价于：先 `iter(iterable)`，然后循环 `next(it)`，用 `check()` 判断是否还有元素。

## 14. 错误与异常

- 运行时错误（类型不匹配、除零、数组越界、方法不存在等）会打印错误信息并终止程序，退出码为 `3`。
- 语言提供轻量级 `Error` 值，主要用于迭代结束和显式错误检查：
  - `error(code)` 创建一个带错误码的 `Error`；
  - `check(val)` 返回 `false` 当且仅当 `val` 是 `Error`；
  - `next` 在迭代结束时返回 `Error`。
- 没有 try/catch 异常机制。`Error` 不是可抛出的异常对象，只是普通值。

---

## 15. 数组与映射

### 15.1 数组

- 字面量：`[1, 2, 3]`；元素可以是任意表达式。
- 内置创建：`array(3)` 创建长度为 3、元素为 `null` 的数组。
- 索引从 0 开始，越界访问或赋值会产生运行时错误。
- 使用 `.size()` 获取长度，`.add(x)` 追加元素。
- 数组可保存任意类型的值，包括函数、类、实例、数组、映射。

### 15.2 映射

- 字面量：`{a: 1, "b": 2}`；值可以是任意表达式，空映射写 `{:}`。注意 `{}` 是空块，不是空映射。
- 键必须是字符串；字面量中的标识符键 `a` 等价于字符串键 `"a"`，也可直接写字符串键。运行时的键可以是 `String` 或 `StrObj`。
- 访问：`m["key"]`、`m.key` 不是映射字段访问语法，映射键统一用 `[]`。
- 设置新键：`m["new"] = value`。
- 使用 `.size()` 获取键值对数量。
- 迭代映射时得到键；顺序由映射内部哈希表决定，不应依赖插入顺序。
- 若用运行时字符串 `StrObj` 作为索引，VM 会自动 `intern()` 后再作为键访问。

---

## 16. 内存管理

- 所有堆对象（数组、映射、类、实例、迭代器、`StrObj`）由 GC 管理。
- GC 是分代式：新生代使用复制收集，老年代使用标记-压缩。
- `String`（驻留字符串）由 VM 直接管理，不参与普通 GC，内容不可变。
- 字符串拼接产生 `StrObj`，可以被 GC 回收。
- 开发者在 Zeta 语言层不需要手动管理内存。

## 17. C++ 互操作

Zeta 提供 C++ 宿主接口（`src/vm/vm.h`），可在 C++ 中：

- 使用 `registerFunction` 注册原生函数；
- 使用 `registerClass` 注册原生类；
- 使用 `call` / `callMethod` 调用 Zeta 函数和方法；
- 使用 `findGlobal` / `getGlobal` / `setGlobal` 读写 Zeta 全局变量；
- 使用 `wrapPointer` / `unwrapPointer` 在 Zeta 对象中保存 C++ 指针；
- 使用 `pushTempRoot` / `popTempRoot` 管理 GC 临时根。

这属于嵌入/宿主 API，具体接口以 `src/vm/vm.h` 和 `tests/cpp/` 中的示例为准。

## 18. 已知限制与注意事项

1. **函数字面量不支持闭包**：不能捕获外层局部变量。
2. **全局 `let` 的不可变性未完全强制**：局部 `let` 赋值会被编译器拒绝，全局 `let` 目前可以被赋值。
3. **全局变量和实例字段的初始化值必须是常量表达式**。
4. **类字段必须用 `var`**，不能用 `let`。
5. **通过类名直接调用方法时，不沿继承链查找**；只查找该类自身的方法表。
6. **特殊协议方法 `_init` / `_equals` / `_iter` / `_next` 不自动继承**，需要在子类中显式定义或调用 `super` 实现。
7. **调用参数最多 255 个**（`uint8_t`）。
8. **没有字符串索引/切片**；字符串只有 `len()` 和拼接。
9. **没有 C 风格 `for(;;)`**；循环只有 `while` 和 `for-in`。
10. **`assert()` 只接受 Bool**，不接受真值转换。
11. **`input()` 读取的是空白分隔 token**，不是整行（当前实现使用 `std::cin >> input`）。
12. **没有 try/catch**，运行时错误直接终止。
13. **没有模块私有/导出控制**，顶层符号默认全部可见。
14. **字节码/序列化格式**相关细节见 `doc/bytecode.md`。
