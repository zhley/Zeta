# Zeta 语言参考手册

版本：0.9.0
更新时间：2026-08-24

Zeta 是一种轻量级动态类型编程语言，支持面向对象和函数式编程。使用栈式虚拟机，带有分代式垃圾回收器。

---
## 1. 词法结构

### 1.1 注释

支持两种注释：

```
// 行注释

/*
   块注释
*/
```

块注释不嵌套。注释等价于空白，在词法分析阶段去除。

### 1.2 标识符

标识符由字母、数字、下划线组成，且不能以数字开头：

```
[a-zA-Z_][a-zA-Z0-9_]*
```

```
// 合法的标识符
hello
aBc666
_zeta
PI_3_1415

// 非法的标识符
233abc
zeta@mail.com
你好
```

### 1.3 关键字

以下单词是保留关键字，不能作为标识符：

```
var let fn return if else while for break continue
class extends this import as super is null true false
```

### 1.4 字面量

#### 整数

支持十进制、二进制、八进制、十六进制，数字间可用下划线 `_` 分隔：

| 形式 | 示例 |
|------|------|
| 十进制 | `42`、`1_000_000` |
| 十六进制 | `0xFF`、`0X1A` |
| 二进制 | `0b1010`、`0B1111` |
| 八进制 | `0o777`、`0o10` |

整数字面量在实现中为 64 位有符号整数（`int64_t`），范围为 -2^63 到 2^63-1。`0` 是合法的十进制零。

#### 浮点数

支持普通小数和科学计数法，也支持下划线分隔：

```
3.14
0.5
1e5
2.5e-3
1_000.5
```

浮点字面量在实现中为 64 位双精度浮点数（`double`）。

#### 字符串

支持单引号和双引号两种字符串字面量：

```
"hello"
'world'
""

// 不同引号支持嵌套
"Alice said: 'Hello!'"
'Bob replied: "Hi!"'

// 同种引号需要转义
"Alice said: \"Hello!\""
'Bob replied: \'Hi!\''

```

支持的转义序列：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |

未知转义序列会保留反斜杠和原字符。

#### 布尔与空值

```
true
false
null
```

### 1.5 语句分隔

语句以分号 `;` 结尾。空语句 `;` 合法。`fn` 声明和 `class` 声明不需要在末尾加分号，变量声明、赋值、`return`、`break`、`continue`、表达式语句等需要分号。

## 2. 程序结构

一个 Zeta 源文件（`.zt`）由以下部分组成：

1. 可选的 `import` 声明；
2. 若干顶层声明：`var` / `let` 全局变量、`fn` 函数、`class` 类。

示例：

```
import "tests/module/mod_a" as a;

var counter = 0;
let PI = 3.14159;

fn add(a, b) {
    return a + b;
}

class Point {
    var x = 0;
    var y = 0;
}
```

顶层声明的顺序不影响符号解析：编译器先登记所有顶层全局符号，再逐个生成代码，因此函数可以互相调用，也可以在定义之前引用。

---

## 3. 类型与值

Zeta 是动态类型语言，变量不声明类型。值在运行时有类型标签。

### 3.1 值类型

| 类型 | 说明 |
|------|------|
| `Null` | 空值，只有一个值 `null` |
| `Int` | 64 位有符号整数 |
| `Float` | 64 位双精度浮点数 |
| `Bool` | 布尔值 `true` / `false` |
| `String` | 驻留字符串，VM 直接管理，内容不可变，存储指向驻留字符串的指针 |
| `Function` | 函数，存储指向运行时例程的指针 |
| `NativeFunc` | 原生函数，存储 C++ 函数指针 |
| `Object` | 对象，存储对象指针，生命周期由 GC 管理 |
| `Error` | 错误标记值，携带整数错误码，用于迭代终止和错误检查 |

Object 类型：
| 类型 | 说明 |
|------|------|
| `Block` | 堆内存块，隐藏类型，语言层面不可见 |
| `Array` | 动态数组 |
| `Map` | 字符串键到值的映射（哈希表） |
| `Class` | 类对象，存储类定义信息 |
| `Instance` | 类的实例对象 |
| `Iterator` | 迭代器对象，用于 `for-in` 循环和 `iter()` / `next()`，专用于数组和映射的迭代 |
| `StrObj` | 字符串对象，内容不可变 |

Object 类型的值都是引用传递，赋值和传参时只复制指针，不复制对象本身。

### 3.2 字符串的两种形态

- **`String`（驻留字符串）**：字符串字面量、编译期常量折叠产生的字符串属于这种类型。它被 VM 内部驻留，可以作为 Map 的键。
- **`StrObj`（GC 字符串对象）**：运行时字符串拼接（例如 `s1 + "lo"`，其中 `s1` 是变量）、`input()`、`str()` 产生这种类型。

二者在底层存在差异，但在语言层面基本等价。注意字符串的相等判定必须使用 `==`，而非 `is`，因为后者会严格按照类型和值进行比较。
`intern()` 函数可显式将 `StrObj` 驻留为 `String`。
此后若称“字符串”，则指两种类型不需要区分。

```
var s1 = "hello"; // String
var s2 = "ze" + "ta"; // String，因为编译期常量折叠，该行等价于 var s2 = "zeta"
var s3 = s1 + ", zeta!" // StrObj，运行时拼接产生 StrObj
var s4 = intern(s3); // String，将 StrObj 驻留为 String
```

### 3.3 真值规则

在 `if`、`while`、`!`、`&&`、`||`、`?:` 等需要条件的位置，以下值视为假：

- `null`
- `false`
- `0`
- `0.0`
- 空字符串
- 空数组
- 空映射

其余值视为真，包括非零数字、非空字符串/数组/映射、函数、类、实例、迭代器、`Error`。

### 3.4 相等与同一

- `==` / `!=` 是值相等比较：
  - Int 与 Float 可以跨类型数值比较；
  - 字符串按内容比较；
  - 实例若在其所属类中定义了 `_equals(other)` 方法，则委托该方法比较，该方法必须恰好接收 1 个参数并返回 Bool，不沿继承链查找 `_equals`。实例未定义 `_equals` 时，只有同一对象才相等（指针比较）；
  - 其他对象（数组、映射、类、迭代器等）按指针比较；
  - 任意两个 `Error` 值 `==` 比较均为 `true`（不比较错误码）。
- `is` 是严格同一性比较：要求类型和值/指针完全相同。

```
0.0 == 0                // true
0.0 is 0                // false
error(1) == error(2)    // true
error(1) is error(2)    // false
```

### 3.5 类型转换内置函数

- `int(x)`：转为 Int。Float 向零截断；Bool 转 `1`/`0`；数字字符串可解析。
- `float(x)`：转为 Float。Int、Bool、数字字符串可转换。
- `str(x)`：转为字符串。Int 和 Float 会生成 `StrObj`；Bool 和 `null` 会返回驻留 `String`（如 `"true"`、`"null"`）。

## 4. 变量与作用域

### 4.1 声明

使用 `var` 声明可变变量，使用 `let` 声明不可变变量：

```
var x;          // 未初始化时值为 null
var y = 10;
let z = "hello"; // 不可变
```

可以在一条语句中声明多个变量：

```
var a = 1, b = 2, c = 3;
```

`let` 也允许不写初始值（值为 `null`），但既然不可变，通常应给出初始值。

### 4.2 局部变量与作用域

- 函数参数是局部变量，属于函数最外层作用域。
- 块 `{ ... }` 会创建新的局部作用域。
- 内层块可以访问外层变量，也可以声明同名变量遮蔽外层变量。
- 同一作用域内不能重复声明同名变量。
- 未初始化的局部变量默认值为 `null`。
- 对 `let` 声明的局部变量赋值会在编译期报错。

示例：

```
fn main() {
    var x = "outer";
    {
        var x = "inner";
        assert(x == "inner");
    }
    assert(x == "outer");
}
```

### 4.3 全局变量

顶层 `var` / `let` 是全局变量。全局变量初始化有以下限制：

- 初始化表达式必须是编译期常量（或者可折叠为编译期常量的表达式）；
- 未初始化时默认值为 `null`。

> 不同于局部变量在编译期检查 `let` 的不可变性，全局变量的 `let` 不可变性在模块加载时检查。

### 4.4 赋值

支持简单赋值和复合赋值：

```
x = expr;
x += expr;
x -= expr;
x *= expr;
x /= expr;
x %= expr;
x &= expr;
x |= expr;
x ^= expr;
x <<= expr;
x >>= expr;
```

复合赋值会读取目标当前值，与右侧表达式运算后再写回。赋值目标可以是局部变量、全局变量、实例字段、数组元素、映射键。

赋值属于独立的语句而非表达式，不产生值。

## 5. 表达式

### 5.1 运算符
#### 5.1.1 算术运算

```
+  -  *  /  %
```

- Int 与 Int 运算产生 Int；除法是整数除法（向零截断）。
- Float 参与时结果为 Float。
- Int 与 Float 混合时，Int 提升为 Float。
- Int 除零或取模零会产生运行时错误。
- 字符串 `+` 表示字符串拼接；结果类型为 `StrObj`，除非在编译期被常量折叠为 `String`。
- 一元 `-` 表示取负数，只能用于 Int 或 Float。

#### 5.1.2 比较运算

```
==  !=  <  >  <=  >=  is
```

- 数值比较支持 Int/Float 混合。
- `<`、`>`、`<=`、`>=` 只支持数值比较。
- `==` / `!=` 按 3.4 节规则。
- `is` 按严格同一性比较。

#### 5.1.3 逻辑运算

```
&&  ||  !
```

- `&&`：先求左操作数；若左操作数为假，返回左操作数本身；否则求右操作数并返回右操作数。结果不一定是 Bool。
- `||`：先求左操作数；若左操作数为真，返回左操作数本身；否则求右操作数并返回右操作数。结果不一定是 Bool。
- `!`：按真值规则取反，结果一定是 Bool。
- `&&` 和 `||` 都遵循短路求值。

#### 5.1.4 位运算

```
&  |  ^  ~  <<  >>
```

- 仅支持 Int 操作数。
- 移位右操作数为 Int 位数。

#### 5.1.5 条件表达式

```
cond ? then_expr : else_expr
```

条件按真值规则判断，只求值被选中的分支。

#### 5.1.6 运算符优先级与结合性

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1 | 一元：`-`、`!`、`~` | 右结合 |
| 2 | 乘除：`*`、`/`、`%` | 左结合 |
| 3 | 加减：`+`、`-` | 左结合 |
| 4 | 移位：`<<`、`>>` | 左结合 |
| 5 | 按位与：`&` | 左结合 |
| 6 | 按位异或：`^` | 左结合 |
| 7 | 按位或：`\|` | 左结合 |
| 8 | 关系：`==`、`!=`、`<`、`>`、`<=`、`>=`、`is` | 左结合 |
| 9 | 逻辑与：`&&` | 左结合 |
| 10 | 逻辑或：`\|\|` | 左结合 |
| 11 | 条件表达式：`?:` | 右结合 |

### 5.2 调用、成员与索引

```
f(args)          // 函数调用
obj.method(args) // 方法调用
obj.field        // 字段访问
obj[expr]        // 数组索引或 Map 键访问
super.method(args)
```

- 函数调用支持表达式作为被调用者，比如 `get_func()(arg1, arg2)`，其中 `get_func()` 返回函数对象。
- 普通函数调用和方法调用是两个不同的语法，比如 `ins.hello()` 表示 `ins` 调用名为 “hello” 的方法，`(ins.hello)()` 表示先取出 `ins` 的 “hello” 字段，然后调用该字段的值（可能是函数对象）。

### 5.3 数组表达式

使用方括号包围元素，元素间用逗号分隔，每个元素可以是任意类型的值或表达式，支持空数组：

```
[1, 2, 3]
["a", "b", "c"]
[1, "hello", null, true, []]
[1 + 2, func(1), obj.field, obj.method()]
[]
```

### 5.4 映射表达式

花括号包裹键值对，键值对之间使用逗号分隔，键必须是字符串字面量或者标识符，值可以是任意类型，支持空映射：

```
{name : "Alice", age : 18, is_student : true}
{"a" : 1, "b" : 2}
{"key" : "value", "num" : 42}
{"string" : 1, identifier : 2}
{:}
```

注意空映射使用 `{:}` 而非 `{}`，后者会被解析成空块。

### 5.5 函数表达式

```
fn (x, y) {
    return x * y;
}
```

属于字面值的一种。

### 5.6 编译期常量折叠

编译器在语法分析阶段会对每个表达式进行简单的折叠尝试，具体而言，只有当表达式中所有操作数都是编译期常量且该运算能在编译期求值时，才会折叠为编译期常量。例如：

```
1 + 2            // 折叠为 Int 3
"a" + "b"        // 折叠为驻留 String "ab"
true ? 1 : 2     // 折叠为 Int 1
true && 12       // 折叠为 Int 12
2 * 3 + 1.0      // 折叠为 Float 7.0
[1, 1 + 2, "a" + "b"] // 折叠为 Array [1, 3, "ab"]
{"a" : 1 + 2}    // 折叠为 Map {"a" : 3}
```

- `"a" + "b"` 等价于字面量 `"ab"`，运行时这是一个驻留字符串，也就是 `String` 类型。
- 数组和映射表达式内部的元素如果是编译期常量，那它本身也是一个编译期常量。
- 函数表达式是编译期常量。

## 6. 语句

### 6.1 变量定义语句

```
var x;
var x = expr;
let x = expr;
```

定义变量，参见第 4 节。

### 6.2 赋值语句

```
x = expr;
x += expr;
```

为变量赋值，参见 4.4 节。

### 6.3 表达式语句

```
expr;
```

表达式结果会被丢弃。

### 6.4 块

```
{
    stmt1;
    stmt2;
}
```

块创建新作用域。

### 6.5 if / else

```
if (cond) stmt
if (cond) stmt else stmt
```

`cond` 使用真值规则。`else` 与最近的未匹配 `if` 结合。

### 6.6 while

```
while (cond) stmt
```

`cond` 使用真值规则。

### 6.7 for-in

```
for (item : iterable) stmt
```

- 对数组：迭代数组元素。
- 对映射：迭代键。
- 对类实例：调用其 `_iter()` 方法获得迭代器，然后不断调用 `_next()` 直到返回 `Error`。
- 循环变量在每次迭代开始时被赋值为当前元素/键。
- 循环变量在 `for` 内部是可变局部变量，但每次迭代会重新赋值。

等价于：
```
var it = iter(iterable);
var item = next(it);
while (check(item)) {
    stmt;
    item = next(it);
}
```

### 6.8 break / continue

- `break`：跳出当前最内层 `while` 或 `for-in`。
- `continue`：跳到当前最内层循环的下一次迭代。
- 在循环外使用会在编译期报错。

### 6.9 return

```
return;
return expr;
```

- 无表达式的 `return` 返回 `null`，即 `return;` 等价于 `return null;`。
- 函数体自然结束也返回 `null`（编译器会在函数末尾自动补 `return null`）。
- 构造函数结束必须 `return this`。

### 6.10 空语句

单独的分号 `;` 是空语句，不执行任何操作。

## 7. 函数

### 7.1 具名函数

```
fn add(a, b) {
    return a + b;
}
```

- 函数是全局符号，可作为值传递、存入数组/映射、作为参数或返回值。
- 函数可以在定义前被调用（因为全局符号先登记）。
- 函数没有默认参数、可变参数、命名参数。
- 必须在顶层定义，不可在局部作用域中定义函数。局部作用域内只能定义成函数变量。

### 7.2 函数字面量（匿名函数 / lambda）

```
fn(x) { return x * 2; }
fn() { return 1; }
```

函数字面量也是 `Function` 值。

### 7.3 高阶函数

函数是一等值，可作为参数传递或返回值：

```
fn apply(f, x) {
    return f(x);
}

fn main() {
    var result = apply(fn(y) { return y + 1; }, 10);
    println(result);
}
```

### 7.4 闭包限制

目前不支持闭包。

函数字面量只能访问：

- 自己的参数；
- 全局变量；
- 其他全局函数/类。

函数字面量不能访问定义它的外层函数中的局部变量。

### 7.5 递归

具名函数可以递归调用自己，因为函数名是全局符号。示例：

```
fn factorial(n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

### 7.6 参数与返回值

- 函数参数按位置传递，参数个数必须与函数声明一致，否则运行时错误。
- 普通函数调用参数上限 255 个。
- 所有函数都会返回一个值；没有 `return` 或 `return;` 时返回 `null`。

## 8. 类与面向对象

### 8.1 类声明

```
class Point {
    var x = 0;
    var y = 0;

    fn set_x(v) {
        this.x = v;
        return this;
    }
}
```

- 类成员包含字段（实例变量）和方法。
- 字段必须用 `var` 声明，不能用 `let`。
- 字段初始化值必须是常量表达式；未初始化时默认 `null`。
- 方法内用 `this` 访问当前实例。

### 8.2 实例化

类是值，调用类即创建实例：

```
var p = Point();
```

若类中定义了 `_init` 方法，则实例化时调用它作为构造函数：

```
class Vec3 {
    var x = 0;
    var y = 0;
    var z = 0;

    fn _init(vx, vy, vz) {
        this.x = vx;
        this.y = vy;
        this.z = vz;
        return this;
    }
}

var v = Vec3(1, 2, 3);
```

- 无 `_init` 时，实例字段使用类中声明的默认值，此时不应传入任何参数。
- 构造函数参数个数不包括 `this`；`Point(1, 2)` 对应 `_init(a, b)`。
- `_init` 不沿继承链继承；子类若需要父类构造逻辑，应在自己的 `_init` 中显式调用 `super._init(...)`。
- 构造函数必须显式 `return this;`。若 `_init` 返回其他值，实例化表达式的返回值将是该值而不是新实例。

### 8.3 字段与方法

- 实例字段通过 `.` 访问和赋值；对不存在的字段赋值会自动创建该字段，读取不存在的字段会报运行时错误。
- 方法通过 `obj.method(args)` 调用；VM 会在实例的类及祖先类的方法表中查找方法。
- 方法内部 `this` 始终是调用该方法的实例；`this` 只能用于方法内，在普通函数中使用会在编译期报错。

### 8.4 继承

```
class Animal {
    var name = "";
    fn speak() { return "Animal " + this.name; }
}

class Dog extends Animal {
    var breed = "";
    fn speak() { return "Dog " + this.name; }
}
```

- 子类实例会继承父类字段（父类默认值会被复制到实例字段表）。
- 普通方法会继承；子类可以重写父类方法，方法查找从实例的实际类开始，沿继承链向上查找。
- 继承语法支持跨模块：`class C extends mod.Base { ... }`，其中 `mod` 是模块别名。

### 8.5 super 调用

```
super.method(args);
```

- `super` 只能在方法内使用。
- `super.method()` 从“当前方法所属类的父类”开始向上查找方法，多级继承链中，每一层的 `super` 都会从该层方法定义所在的类向上解析。
- `super._init(...)` 可用于在子类构造函数中调用父类构造函数。

### 8.6 类名调用方法

可以通过类名直接调用方法，例如：

```
class A { fn who() { return "A"; } }
class B extends A { fn who() { return "B+" + super.who(); } }

fn main() {
    var b = B();
    assert(B.who(b) == "B+A");
    assert(A.who(b) == "A");
}
```

通过类名调用方法时，第一个参数作为 `this` 传入。注意：通过类名调用方法只查找该类自身的方法表，不会沿继承链向上查找。

### 8.7 类作为值

- 类可以赋值给变量、存入数组/映射、作为参数/返回值。
- 通过保存类的变量调用它同样可以实例化。

### 8.8 特殊协议方法

以下方法名具有特殊运行时含义：

| 方法 | 用途 |
|------|------|
| `_init` | 构造函数 |
| `_equals(other)` | 自定义 `==` / `!=` 的实例比较；必须接收 1 个参数并返回 Bool |
| `_iter()` | 自定义 `for-in` / `iter()` 时返回迭代器，必须返回实现了 `_next` 方法的实例对象 |
| `_next()` | 自定义迭代器的“取下一个元素”方法；无参数，迭代结束时返回 `error(0)` |

> 当前实现中，这些特殊方法按“实例所属类自己的方法表”直接查找，不沿继承链自动继承。如果父类定义了这些方法而子类没有，子类实例不会自动获得父类的构造/比较/迭代行为；请在子类中显式定义或通过 `super` 调用父类实现。

## 9. 模块系统

### 9.1 导入

```
import "path/to/module";
import "path/to/module" as alias;
```

- 导入路径是模块名，**不带扩展名**。
- 例如 `import "tests/module/mod_a"` 会查找 `tests/module/mod_a.ztc` 或 `tests/module/mod_a.zt`。
- 带 `as` 时，通过 `alias.symbol` 访问该模块的全局符号。
- 不带 `as` 时，该模块的全局符号可直接使用。

> 推荐使用别名以避免命名冲突。

### 9.2 查找顺序

对于 `import "name"`，VM 按以下顺序查找模块文件：

1. 相对于“导入该模块的模块”所在目录：`<base_dir>/name.ztc`，然后是 `<base_dir>/name.zt`；
2. 相对于当前工作目录（或绝对路径）；
3. 依次在 `-p` 指定的模块搜索路径中查找。

当两种模块文件同时存在时，优先使用字节码文件 `.ztc`。

### 9.3 符号解析

- 使用别名时，`alias.name` 会解析为指定模块中名为 `name` 的全局符号。
- 不使用别名时，未限定名称会按 `import` 的声明顺序在已导入模块中查找；如果多个模块都定义了同名符号，则使用第一个导入模块中的定义。建议避免依赖这种顺序，必要时使用别名。
- 若模块别名与当前模块的全局符号同名，别名优先。
- 同一个 VM 中每个模块只加载一次，所有模块共享全局运行时状态；因此模块级 `var` 是跨模块共享的可变状态。
- 模块之间允许传递依赖：A 导入 B，B 导入 C；A 中只能直接使用 A 的 `imports` 中列出的模块符号，不能直接使用 B 的内部依赖 C（除非 A 自己也显式导入 C）。

### 9.4 模块导出

Zeta 没有显式的 `export` 关键字。模块的所有顶层 `var` / `let`、函数、类默认对导入者可见。

## 10. 内置函数与方法

### 10.1 内置函数

以下函数由 VM 直接实现，不需要从任何模块导入。它们也是保留的全局名字，不能用来声明同名函数（编译期会报冲突）。

#### 10.1.1 内置函数列表

| 函数 | 签名 | 说明 |
|------|------|------|
| `iter` | `iter(container)` | 返回容器或类实例的迭代器 |
| `next` | `next(iter)` | 取迭代器的下一个元素；迭代结束返回 `Error` |
| `array` | `array(size)` | 创建指定大小的数组，元素初始化为 `null` |
| `map` | `map(capacity)` | 创建空映射，`capacity` 为初始容量提示 |
| `print` | `print(val)` | 打印值到标准输出，不换行；返回 `null` |
| `println` | `println(val)` | 同 `print`，但末尾换行；返回 `null` |
| `input` | `input()` | 从标准输入读取一个以空白分隔的字符串，返回 `StrObj` |
| `error` | `error(code)` | 创建一个错误码为 `code` 的 `Error` 值 |
| `check` | `check(val)` | 若 `val` 是 `Error` 返回 `false`，否则返回 `true` |
| `intern` | `intern(strObj)` | 将 `StrObj` 驻留为 `String` 并返回；用于 Map 键 |
| `type` | `type(val)` | 返回类型名字符串（驻留 `String`） |
| `int` | `int(val)` | 转换为 Int |
| `float` | `float(val)` | 转换为 Float |
| `str` | `str(val)` | 转换为字符串；Int/Float 生成 `StrObj`，Bool/`null` 返回 `String` |
| `assert` | `assert(cond)` | `cond` 必须是 Bool；若为 `false` 抛出运行时错误 |

#### 10.1.2 打印格式

`print` / `println` 对不同类型的输出格式：

| 值 | 输出 |
|------|------|
| `null` | `null` |
| `Bool` | `true` / `false` |
| `Int` | 十进制整数 |
| `Float` | 使用 C++ `cout` 默认格式 |
| `String` / `StrObj` | 字符串内容（不含引号） |
| `Function` | `<function>` |
| `Array` | `<array>` |
| `Map` | `<map>` |
| `Class` | `<class>` |
| `Instance` | `<instance>` |
| `Iterator` | `<iterator>` |
| `Error` | `<error>` |

### 10.2 内置方法

| 接收者 | 方法 | 签名 | 说明 |
|--------|------|------|------|
| 数组 | `size` | `arr.size()` | 返回数组元素个数 |
| 数组 | `add` | `arr.add(value)` | 在数组末尾追加一个元素；返回 `null` |
| 映射 | `size` | `m.size()` | 返回映射键值对个数 |
| `String` / `StrObj` | `len` | `s.len()` | 返回字符串长度（字节数） |

数组、映射、字符串的内置方法由 VM 直接处理，不经过类方法表。实例也可以定义同名方法，实例方法调用会走正常方法分派。

## 11. 迭代协议

### 11.1 数组和映射

- `iter([1, 2, 3])` 返回数组迭代器，`next` 依次返回元素。
- `iter({a: 1})` 返回映射迭代器，`next` 依次返回键（驻留 `String`）。
- 迭代结束后，`next` 返回 `Error`，`check(next(...))` 为 `false`。

### 11.2 自定义类迭代

一个类只要实现 `_iter()`，并返回实现了 `_next()` 的自定义迭代器，就可以被 `for-in` 使用：

```
class Range {
    fn _iter() {
        return RangeIter(this.start, this.end);
    }
}

class RangeIter {
    fn _next() {
        if (this.current >= this.end) {
            return error(0);
        }
        var v = this.current;
        this.current = this.current + 1;
        return v;
    }
}
```

- `_iter()` 必须返回一个迭代器对象（通常是一个类实例）。
- `_next()` 每调用一次返回下一个元素；迭代结束时返回 `error(0)`。

## 12. 错误处理

- 运行时错误（类型不匹配、除零、数组越界、方法不存在等）会立即终止运行。
- 语言提供轻量级 `Error` 类型：
  - `error(code)` 创建一个带错误码的 `Error`；
  - `check(val)` 返回 `false` 当且仅当 `val` 是 `Error`；

---

## 13. 数组与映射

### 13.1 数组

- 字面量：`[1, 2, 3]`；元素可以是任意表达式。
- 内置创建：`array(3)` 创建长度为 3、元素为 `null` 的数组。
- 索引从 0 开始，越界访问或赋值会产生运行时错误。
- 使用 `.size()` 获取长度，`.add(x)` 追加元素。
- 数组可保存任意类型的值，包括函数、类、实例、数组、映射。

### 13.2 映射

- 字面量：`{a: 1, "b": 2}`；值可以是任意表达式，空映射写 `{:}`。注意 `{}` 是空块，不是空映射。
- 键必须是字面量字符串；字面量中的标识符键 `a` 等价于字符串键 `"a"`，也可直接写字符串键。
- 访问：`m["key"]`、`m.key` 不是映射字段访问语法，映射键统一用 `[]`。
- 设置新键：`m["new"] = value`。
- 使用 `.size()` 获取键值对数量。
- 迭代映射时得到键；顺序由映射内部哈希表决定，不保持插入顺序。
- 若用运行时字符串 `StrObj` 作为索引，VM 会自动 `intern()` 后再作为键访问。

## 14. 内存管理

Zeta 使用分代式垃圾回收器管理堆内存，分配在堆区的对象包括 `Array`、`Map`、`Class`、`Instance`、`Iterator`、`StrObj`。不再使用的对象会被自动回收，无需手动管理。

## 16. 注意事项

1. **函数字面量不支持闭包**：不能捕获外层局部变量。
2. **全局变量和实例字段的初始化值必须是常量表达式**。
3. **类字段必须用 `var`**，不能用 `let`。
4. **通过类名直接调用方法时，不沿继承链查找**；只查找该类自身的方法表。
5. **特殊协议方法 `_init` / `_equals` / `_iter` / `_next` 不自动继承**，需要在子类中显式定义或调用 `super` 实现。
6. **`assert()` 只接受 Bool**，不接受真值转换。
7. **`input()` 读取的是空白分隔 token**，不是整行。
8. **构造函数必须显式 `return this`**。
9. **源文件使用 UTF-8 编码**，注释内可使用任何字符，字符串目前未做编码适配，建议只使用 ASCII 字符。
